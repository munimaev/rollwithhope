Если вы перематываете историю вперёд на несколько дней (или дольше), вам, вероятно, не нужна отдельная сцена для каждого долгого отдыха в этот период. Для таких долгих отрезков вы можете обсудить с игроками, чего их персонажи хотят достичь, а затем использовать монтаж, чтобы показать, как проходит время.

Вы получаете 1d6 Страха за каждого персонажа игрока и можете продвинуть долгосрочные счётчики так, чтобы это соответствовало проходящему времени.

Для некоторых целей персонажей может хватить одного броска (или вовсе не потребоваться бросков). Другие могут потребовать серию бросков для продвижения счётчика прогресса, чтобы продвинуть проект на протяжении нескольких долгих отдыхов. Например, для барда собрать слухи за недельное пребывание в городе — пустяковое дело, но вы можете попросить его совершить бросок Влияния, чтобы выяснить, узнает ли он особенно важную информацию. Аналогично вы можете попросить воина совершить бросок Искусности, если он пытается улучшить свою броню редкими материалами, добытыми в предыдущем приключении.
