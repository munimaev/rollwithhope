В этом разделе вы можете найти описания всех классов Daggerheart.

Выбранный вами класс предоставляет следующее:

🟨 Домены

Каждый класс указывает, какие два домена лежат в основе его способностей. Это определяет, из каких колод доменов вы можете выбирать карточки при создании персонажа и при повышении уровня.

🟨 Стартовое уклонение

У каждого класса свой стартовый показатель Уклонения.

🟨 Стартовый максимум Ран

У каждого класса свой стартовый максимум Ран, которые он может получить.

🟨 Предметы класса

У каждого класса есть уникальный набор предметов, с которыми он начинает игру.

🟨 Свойство класса

У каждого класса есть уникальное свойство класса (или набор свойств).

🟨 Свойство Надежды класса

У каждого класса есть особый ход, который можно использовать, потратив три Надежды.

Выбранный вами подкласс дает следующее:

🟨 Атрибут магии

Если вы заклинатель, то это атрибут персонажа, который использует ваш подкласс всякий раз, когда вам нужно совершить бросок заклинания.

🟨 Свойство основы

Это уникальное стартовое свойство, которое закладывает отличительные черты и сильные стороны подкласса.

🟨 Свойство специализации

Это более продвинутое свойство (или набор свойств), которое вы получаете при повышении уровня. У одних подклассов это — новая способность, у других — расширение существующих способностей класса или свойства основы, делающее их ещё более сильными.

🟨 Свойство мастерства

Это самое сильное свойство вашего подкласса, которое становится доступным на более высоких уровнях. У одних подклассов оно открывает невероятную новую способность, у других — представляет собой впечатляющую кульминацию ключевого свойства подкласса.

Свойства основы, специализации и мастерства также отражены на соответствующих карточках, которые вы можете выбрать в качестве одного из вариантов при повышении уровня. Эти карточки содержат информацию о свойствах для быстрого доступа.

В следующих разделах, посвящённых классам, упоминаются многие механики и термины, которые будут подробно объясняться во второй главе. Используйте оглавление, чтобы при необходимости быстро перейти к нужному понятию.
