# sync-content

Обновление контента сайта rollwithhope из личного Obsidian-хранилища DaggerHeart.
Контекст и границы описаны в `CLAUDE.md` репозитория — прочитай его в начале работы,
если ещё не прочитан в этой сессии.

## Три места

1. Хранилище Obsidian (`VAULT_PATH`, обычно
   `.../iCloud~md~obsidian/Documents/DaggerHeart`) — источник контента, приватный.
2. Этот репозиторий: `src/` (код) + `content/` (**вычисляемое**, генерируется `sync`,
   руками не трогать).
3. `96︱🛠️︱Сайт` внутри хранилища — редактируемая вручную конфигурация (`Разделы.yml`,
   `Слаги.yml`, `Архитектура.md`, `Design System/`), которую тоже читает `sync`.

## Обязательное правило публикации

- Только заметки с `visibility: public` во frontmatter идут на сайт. Без этого поля —
  приватная по умолчанию.
- Картинка/файл попадает в `content/images/` только если на неё ссылается публичная
  заметка.
- Не смягчать это правило ради удобства — приватный контент не должен оказаться ни в
  `content/`, ни тем более в истории публичного репозитория на GitHub.

## Шаги обновления контента

1. Убедиться, что известен актуальный `VAULT_PATH` (спросить пользователя, если не
   указан в этой сессии).
2. Свериться с `96︱🛠️︱Сайт/Архитектура.md` в хранилище — это источник истины по
   деталям пайплайна (слаги, картинки, вики-ссылки, callout'ы), а не пересказ здесь.
3. Прогнать `VAULT_PATH=... npm run sync` (или `sync:strict`, если нужно ловить все
   предупреждения как ошибки). Это чисто локальная операция — ничего не пушит, можно
   запускать свободно.
4. Прочитать отчёт sync (добавлено / изменено / пропало / предупреждения). Пропавшее —
   заметки, ставшие приватными; предупреждения — висячие вики-ссылки на приватное или
   картинки, исключённые по политике.
5. Посмотреть `git diff` в `content/`, чтобы понять, что реально изменилось.
6. **Перед push** — обязательно явное подтверждение пользователя + проверка, что в
   `content/` не осталось заметок без `public`. Без этого не пушить.

## Формат генерируемых страниц

`content/pages/**/*.vue` — настоящие Vue SFC (решение от 2026-09-23, не `.html`+v-html,
как было раньше до сброса фронтенда). Разметка внутри следует markup-контракту из
`templates/guidelines/40-markup-contract.md` (тот же контракт, что использует дизайн-система
в `templates/`). `templates/` — локальный (gitignored) снимок дизайн-системы для справки при
реализации `src/components/*.vue`, не копировать оттуда напрямую.

## Чего не делать

- Не редактировать руками ничего внутри `content/` — следующий `sync` всё перезапишет.
- Не публиковать заметки/картинки без `visibility: public` ни при каких условиях.
- Не пушить в GitHub без отчёта sync и подтверждения пользователя.
- Не копировать логотип/шрифты/вёрстку официальной книги Daggerheart (см. дизайн-гайд в
  `templates/`) — у сайта свои знак, палитра и рамки.
